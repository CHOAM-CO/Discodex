Discodex는 Discord 앱 프로필 하나를 지속 대화 하나에 연결합니다. 채팅과 음성은 Codex 문맥을 공유하며, 선택적으로 Antigravity CLI를 텍스트 대화에 사용할 수 있습니다. 기본 작업과 하위 에이전트 관리는 함께 배포하는 Codex 포크가 맡습니다.

이 문서는 1.0 소스 기준입니다. 다운로드 파일은 게시된 릴리스 태그를 따릅니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 지속되는 문맥 | 워커 재시작이나 음성 통화 후에도 같은 Codex 대화를 이어갑니다. |
| 음성과 전사 | 허용된 음성 채널에서 대화하고, 확정 전사는 통화별 Discord 스레드에 남깁니다. |
| 질문과 승인 | Codex의 질문·승인 요청을 Discord 폼과 버튼으로 전달하고 해당 요청에 응답합니다. |
| 에이전트 설정 | 프로필 이름과 언어를 정하고, 버튼으로 모델·추론 강도·권한·음성·입력 방식을 선택합니다. 선택적 `memoryEnabled` 설정은 native 메모리와 전용 도구를 함께 활성화합니다. |
| 기본 Discodex 스킬 | 설치 언어의 안내와 해당 빌드의 설치·설정·문제 해결 참고 문서를 제공하고, 업데이트 시 관리 파일을 갱신합니다. |
| Discord 문맥과 첨부 | 채널·스레드·메시지를 조회하고 첨부를 다운로드하거나 전송합니다. 답변의 Markdown 파일 링크도 실제 첨부로 바꿉니다. |
| 메시지 수신 설정 | 전체 사용자·등록 서버·등록 채널·페어링 사용자 정책과 별도의 허용·차단 목록을 관리합니다. |
| Markdown 표 | 완료된 일반 답변과 `discord_send_message`의 표를 줄바꿈·페이지 분할 PNG 첨부로 표시하며 굵게·기울임·밑줄 등 인라인 서식을 보존하고 주변 문장도 유지합니다. 언어별 **원문 보기** 버튼은 누른 사용자에게 복사할 수 있는 Markdown 원문을 페이지로 보여 줍니다. |
| 계획과 작업 | 변경된 계획마다 새 홈채널 Embed 카드를 게시하며 이전 카드는 수정하지 않습니다. 완료/전체 수, 완료 체크와 취소선, 진행 중 화살표, 대기 표시와 상태색을 보여 주며 동일 이벤트 재생은 생략하고 전체 계획 텍스트는 Discord의 실제 한도에 맞춰 페이지로 나눠 보존합니다. native `update_plan`과 작업·관리 워크트리 도구는 같은 대화 문맥을 유지합니다. |
| 업데이트 알림 | 유휴 상태에서 업데이트·이번 버전 스킵·알림 끄기를 선택하고, 기존 프로필을 유지한 채 사전 빌드 파일을 적용합니다. |
| Native 기능 | 프로필별 `native-features.json`에서 공식 app-server 기능을 관리합니다. 설정은 실제 적용 상태와 저장값을 구분하고 재시작이 필요한 변경을 표시합니다. |
| 플러그인 | `/discodex plugins`에서 현재 native 카탈로그를 확인하고 Discord 버튼으로 지원되는 읽기·설치·제거를 실행합니다. 추천과 인증은 공식 native 절차를 따릅니다. |
| 비동기 질문과 알림 | native 질문에 Discord 버튼이나 자유 입력으로 답하면 원래 질문 ID와 thread에 연결됩니다. 비동기 알림은 진행 중 turn을 끝내지 않고 홈채널에 표시됩니다. |
| 이벤트 처리와 로그 | 메인 제어 이벤트는 감시되는 소비자가 처리하고, 프로필별 로그를 저장해 콘솔 없이 실행한 Windows GUI worker의 문제를 확인할 수 있습니다. 업데이트는 사전 빌드 파일을 사용합니다. |

## 시작하기

[최신 릴리스](https://github.com/CHOAM-CO/Discodex/releases/latest)에서 `discodex-installers.zip`을 내려받아 압축을 풀고 해당 폴더에서 실행합니다. 설치 스크립트가 운영체제와 아키텍처에 맞는 워커와 관리형 Codex 런타임을 받으므로 Rust·Cargo·Git은 필요하지 않습니다. 계정·메모리·기록을 공유할 기존 Codex 홈(발견 시 권장) 또는 Discodex 전용 홈을 선택하며 공유 Codex 설정은 보존합니다.

```sh
./install
```

Windows PowerShell에서는 `./scripts/install.ps1`을 실행합니다. 설치기에서 English(기본값), 한국어, 简体中文, 日本語를 선택합니다. 선택한 언어는 설치 안내, Discodex의 Discord UI, 에이전트 기본 지침에 적용됩니다. `DISCODEX_LANGUAGE=en`, `ko`, `zh`, `ja`를 미리 지정하면 언어를 다시 묻지 않습니다.

설치기는 Codex와 Discord 연결, 프로필 및 사용자 범위 자동 시작을 설정합니다. 기존 설치의 migration, 업데이트, 제거는 [설치 안내](docs/installation.ko.md)를 참고하세요.

## 사용자 지정 및 로컬 모델

메인 모델과 **기본 하위 에이전트 모델**에는 native 카탈로그와 명시적으로 등록한 공급자·모델이 표시됩니다. 함께 배포하는 포크는 부모와 다른 공급자로 하위 에이전트를 만들 수 있습니다. 저장한 하위 에이전트 기본값은 다음 스레드 생성·재개 시 읽으며, 워커 재시작 후 재개에도 적용됩니다. 현재 스레드의 실효 설정은 재개 전까지 유지하고, 기존 자식의 설정과 부모 대화는 보존합니다. 공급자 인증과 모델 기능은 Codex가 처리합니다. 예시는 [공급자 설정 안내](docs/installation.ko.md#사용자-지정-및-로컬-codex-provider)를 참고하세요.

공급자 기록 호환성은 `encrypted_content`와 `agent_messages`를 독립적으로 설정합니다. 읽을 수 있는 문맥은 전송 형식에 보존하며 저장된 원본 기록은 바꾸지 않습니다. 자세한 내용은 [기록 호환성](docs/design.ko.md#공급자-변경과-암호화된-기록)을 참고하세요.

**고급 설정 → Antigravity**를 켜면 공식 사전 빌드 릴리스로 프로필 전용 AGY CLI를 준비합니다. 필요한 설치와 native 로그인을 시작하며, 도중에 취소하거나 나갈 수 있습니다. 브라우저의 로그인 동의는 사용자가 완료합니다. 설치기와 Discord 설정에서 기존 AGY 설정 공유 또는 Discodex 전용 설정을 선택할 수 있고, 운영체제의 계정 키링은 AGY 기본 동작을 따릅니다. Discodex 제거 시 전용 AGY 실행 파일을 삭제하며 외부 AGY 설치와 공유 설정은 보존합니다.

정확한 모델 ID·이름은 `agy models`에서, 추론 강도 선택지는 CLI `--help`에서 가져옵니다. 직접 입력한 모델 ID로 목록을 보충할 수 있습니다. 조회 오류를 표시하고 명시한 미지원 추론 강도도 바꾸지 않고 CLI에 전달합니다. SDK 대신 구독 로그인한 AGY CLI를 사용합니다. 겹치는 기본 도구는 AGY가 실행하고 추가 Discord·작업 도구는 MCP로 연결하며, 하위 에이전트는 Codex 포크가 관리합니다. 응답마다 새 CLI에 native 대화와 읽을 수 있는 도구 결과를 전달하며 AGY 비공개 상태는 재개하지 않습니다. AGY 설정은 다음 모델 선택 또는 실행 때 적용됩니다. 메인 작업에 AGY나 로컬·사용자 지정 모델을 선택해도 음성은 선택한 Codex 계정의 Realtime 연결을 사용합니다.

## 업데이트

`/discodex update`는 최신 릴리스를 즉시 확인합니다. **업데이트 / 취소** 화면에서 하위 에이전트를 포함한 진행 중 작업과 음성 통화가 중단됨을 안내합니다. 업데이트를 확인하면 유휴 대기열 없이 적용하고, 재시작 후 홈채널에 완료 또는 실패를 알립니다. 중단한 응답은 자동 재시작하지 않으며 재개 프롬프트나 빈 입력도 넣지 않습니다.

자동 확인은 성공 후 6시간, 실패 후 15분 간격이며 알림은 5분 유휴 상태에서 표시합니다. 알림에는 **업데이트**, **이번 버전은 스킵**, **다시 알리지 않음**이 있습니다. 이 시간 조건은 알림에만 적용하며 확인한 업데이트를 지연시키지 않습니다.

수동 업데이트는 설치 스크립트 묶음으로 실행합니다.

```sh
./update --config "<기존-config.json-경로>"
```

```powershell
./scripts/update.ps1 -Config "<기존-config.json-경로>"
```

워커와 그 버전에 맞는 사전 빌드 Codex 패키지를 내려받습니다. 매니페스트에는 워커 버전, 포크 커밋, 플랫폼과 체크섬이 고정됩니다. 런타임 준비 후 선택한 프로필의 소유 파일만 교체합니다. 교체나 재기동 실패 시 이전 워커·프로필 설정·런타임 참조·소유 기록·서비스 상태의 복원을 시도합니다. 필요한 복원 단계가 실패하면 후속 의존 단계를 멈추고 원인을 표시하며, 이전 파일과 새 파일이 섞인 상태로 재시작하지 않습니다. 사용하지 않는 준비된 런타임은 필요한 서비스 복원 뒤에 정리하며, 정리 실패도 표시합니다. Codex 홈·계정·메모리·대화 기록·설정은 유지합니다. 기존 0.1.x 셀프 업데이터의 실행 파일명과 helper 진입점은 그대로이며, 0.1.3 이전 설치는 수동 스크립트로 먼저 업데이트해야 합니다. 사용자 기기에서 소스를 빌드하지 않습니다.

## Discord 명령

설정 패널에서 메인 모델·기본 하위 에이전트 모델·추론 강도·Fast 모드·권한 프로필·승인 방식·입력 전달 방식·음성·수신 정책·업데이트 알림을 선택합니다. 승인 방식 기본값은 **on-request**이며 권한 프로필과 별개입니다. **고급 설정**은 세부 native 기능을 모으며 하위 에이전트 모델을 중복 표시하지 않습니다. 허용·차단 목록은 현재 서버 닉네임으로 조회하고 계정 ID를 입력해 추가·삭제합니다. 세부 화면은 뒤로가기, 메인 목록은 나가기를 제공합니다. 음성 프로필 변경은 다음 통화부터 적용됩니다. 승인 선택은 프로필별 `native-features.json`에 저장하며 공유 Codex 설정을 덮어쓰지 않는다.

- `/discodex settings`: 버튼으로 설정 선택
- `/discodex voice`: 음성 프로필 선택
- `/discodex status`: 대화와 설정 확인
- `/discodex voice-join channel:<허용 음성 채널>`: 음성 입장
- `/discodex voice-leave`: 음성 통화 종료
- `/discodex interrupt`: 진행 중 응답 중단 요청
- `/discodex compact`: 현재 대화 문맥을 수동 압축
- `/discodex update`: 업데이트 확인 및 적용
- `/discodex new`: 새 대화 시작

수신 정책은 발신자의 허용 여부를 정하고, 입력은 홈 채널·봇 멘션·등록 채널/스레드·허용된 DM 경로를 따릅니다. 일반 답변은 홈채널에 모이며 답장할 상대를 멘션하도록 안내합니다. 다른 채널에서 실시간으로 받은 글에 답할 때는 전송 도구로 원래 채널에 보내며, 그 밖의 별도 발송은 명시적으로 요청합니다. 통화 중에는 현재 전사 스레드의 글과 첨부를 바로 전달하고, 그 밖의 입력은 짧은 미리보기만 알립니다. 에이전트는 대화에 필요하거나 사용자가 요청할 때 수신함을 조회하고, 미조회 메시지는 통화 종료 뒤 처리합니다.

페어링 사용자와 허용 목록 사용자의 DM은 선택한 서버·채널 수신 정책과 관계없이 멘션 없이 받는다. 차단 목록과 자기 메시지 제외가 우선하며, `Everyone`은 그 밖의 DM 발신자도 허용한다. 일반 자동 출력·질문·승인·진행 안내는 홈 채널을 유지한다. 실시간으로 받은 DM에 답할 때는 `source.dm_id`를 대상으로 `discord_send_message`를 호출해 원래 DM에 보낸다.

음성 통화를 끝내도 지속 대화는 유지됩니다. v0.1.3 이전 설치는 다운로드한 업데이트 스크립트로 한 번 전환하면 이후 Discord 업데이트 버튼도 사전 빌드 파일을 사용합니다. 문서: [설치와 제거](docs/installation.ko.md) · [제품 설계](docs/design.ko.md)
