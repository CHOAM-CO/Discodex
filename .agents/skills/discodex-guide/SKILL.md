# Discodex 사용 안내

Discodex는 Discord 앱 하나를 공식 Codex의 지속 thread 하나에 연결한다. 업무 판단과 Codex 도구 실행은 공식 Codex가 맡는다.

- [Discord 대화](references/discord.md): 입력과 답장, 질문·승인, 음성 기록.
- [명령 사용법](references/usage.md): 등록된 `/discodex` 명령과 제한.

모델·추론 강도·서비스 등급은 현재 native model catalog, 권한은 허용된 native permission profile에서 조회한다. 제공 목록에 없는 설정을 가정하지 않는다. Slash command는 Discord application interaction으로 실행한다.
